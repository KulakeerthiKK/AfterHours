1. Executive Summary & The Problem Space

Modern application security faces a severe scalability bottleneck. Traditional Static Application Security Testing (SAST) tools generate high volumes of false positives without contextual understanding, while Dynamic Application Security Testing (DAST) tools perform blind network fuzzing that triggers firewall rate-limits and lacks source-code awareness. More critically, neither paradigm writes, tests, or verifies code patches—forcing engineering teams into manual triage, alert fatigue, and protracted remediation cycles that average 45+ days per vulnerability.

AEGIS-AGENT solves this by introducing a closed-loop, autonomous multi-agent platform inspired by modern autonomous security engineering (such as XBOW), pairing high-contrast visual war room telemetry with rigorous mathematical and deterministic verification bounds:

Core Autonomous Capabilities:
  • Context Ingestion: Ingests Git repositories and OpenAPI 3.0 specs to extract an Abstract Syntax Tree (AST) attack surface before sending any probes.
  • Empirical Proof-of-Exploit: Executes non-destructive, controlled syntax breaker probes against sandboxed local endpoints to prove exploitability.
  • Automated Patch Synthesis: Fix Agent uses LLMs (via OpenRouter AI) to write minimal, production-grade unified diff patches.
  • Dual-Check Regression Testing: Auditor Agent verifies in an isolated worktree that the exploit is neutralized while authentic application behavior remains intact.
Zero-Risk Safety Governance:
  • Strict Target Allowlisting: Rejects all arbitrary external scanning; external URLs are safely mapped to the local container SEC-LOCAL-8080.
  • Human-in-the-Loop Gatekeeper: Candidate patches are synthesized in disposable worktrees and never committed, merged, or pushed without explicit operator authorization.
  • Zero Dependencies: Co-hosts frontend SPA and backend REST API on port 3000 using native Node.js core modules.
  • Persistent Embedded Database: Persistent storage via native SQLite (node:sqlite) with optional PostgreSQL pool fallback.

4. User Interface Architecture & Sitemap

The application is structured as a zero-latency Single Page Application (SPA) with 8 primary views:

1. Landing Overview (`#landing`)

Split hero layout with animated typewriter terminal console (aegis-ast-trace@local), 4 KPI metric counters, one-click Run Security Assessment button, 60s Guided Tour launcher, 6-stage interactive feature showcase, and multi-language API quick-starts (cURL, PowerShell, Node.js, Python).

2. Target Research & Ingestion (`#research`)

Input card for Git repository URL, branch ref, staging URL, and API spec. Features 4 quick preset chips (Auth Microservice, Session Gateway, Report Exporter, Custom Target). The right pane displays real-time AST surface extraction, detected technology stack, and parameter risk tiers.

3. Security War Room (`#war-room`)

Mission control cockpit featuring a live multi-agent network visualizer, millisecond stopwatch (⏱ 00:04.2s), laser progress bar (0% → 100%), speed controls (0.5x, 1x, 2x, Fast), simulation state toggles (Pause/Resume, Step, Reset), and audio synthesizer chimes.

4. Attack Path Visualizer (`#attackpath`)

Interactive node-and-edge attack graph with animated dashed SVG connectors illustrating: Ingress Entrypoint → Vulnerable Component → Reachable Asset Impact. Includes slide-out Evidence Inspector Drawer for inspecting HTTP payloads.

5. Finding Inspector (`#findingdetail`)

Deep-dive vulnerability analyzer featuring CVSS 1.0–10.0 risk score badges, captured HTTP probe requests and response traces, local Semgrep AST scan triggers, SARIF JSON export, and operator Human-in-the-Loop decision controls (Approve Patch, Reject Patch, Run Auditor Check).

6. Governance Dashboard & Logs (`#dashboard`, `#logs`)

Searchable historical audit log of all runs with severity filters (All, High, Medium, Remediated), persistent SQLite records, and real-time streaming system telemetry logs with colored agent tags.

The backend provides a RESTful API co-hosted with the frontend on port 3000:

Method Endpoint Payload / Parameters Response Description

POST /api/reset None Resets in-memory workflow runs, cache, and findings to clean initial state.

7. Step-by-Step Operator Manual: How to Run & Obtain Output

Scenario A: Fastest Quick-Start (One-Click Autonomous Demo)
  1. Open the Application: Launch your browser and navigate to http://localhost:3000.
  2. Click "Run Security Assessment": On the Landing Page hero, click the lime button: Run Security Assessment.
  3. Watch Real-Time Execution: The view switches automatically to the War Room (`#war-room`). Watch the progress bar advance from 0% → 100% as the Scope Controller, Red Agent, Sentinel Agent, Fix Agent, and Auditor Agent coordinate synchronously.
  4. Inspect Outputs: Once complete, inspect the captured error trace under Finding Dossier, review the unified diff under Proposed Fix, and verify that regression checks passed under Regression Audit.
Scenario B: Ingestion & Target Research (Custom URL / Portfolio Demo)
  1. Navigate to Target Research: Click Target Research in the navbar (or visit http://localhost:3000/#research).
  2. Select a Preset or Custom URL:
    • Click Session Gateway (JWT Auth) to test JWT algorithm "none" bypass.
    • OR click + Custom Target and enter your own staging link (e.g. https://abhi-portfolio-wheat-s.vercel.app). The system automatically maps your target to the safe container SEC-LOCAL-8080.
  3. Ingest Target Surface: Click the green button: Ingest Target & Discover Surface. The right column instantly extracts discovered endpoints, parameter risk levels (High, Medium, Critical), and technology stack.
  4. Launch Assessment: Click Launch Live War Room →. The system starts the assessment with the selected target and recommended CWE test case.
Scenario C: How to Export All Output Deliverables
  1. cURL Reproduction Command: In the War Room under the Finding Dossier subtab, click Copy cURL to copy the exact HTTP exploit command to your clipboard.
  2. Unified Git Diff (.patch): Under the Proposed Fix subtab, review the additions/deletions, toggle to Split View, and click Approve & Apply Patch to simulate applying the patch.
  3. SARIF JSON Security Vulnerability File: Navigate to Finding Detail (`#findingdetail`) and click Export SARIF JSON to download the standard SARIF vulnerability artifact for security scanners.
  4. Executive PDF Report: Open or download the generated comprehensive PDF documentation directly from the local server: http://localhost:3000/AEGIS_AGENT_Complete_Project_Overview.pdf.
