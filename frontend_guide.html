01. Frontend Architectural Philosophy & Tech Stack

The AEGIS-AGENT front end is built strictly on zero-dependency modern web standards. Instead of shipping bloated node_modules or requiring complex build steps, the entire UI is delivered via raw HTML5, highly optimized CSS3 custom variables, and a modular JavaScript controller.

Why Zero Dependencies?

  • Instantaneous Cold Starts: Loads in under 80 milliseconds directly off disk or the local Node.js server.
  • Offline & Sandbox Resilient: Immune to npm package failures, broken lockfiles, or sandboxed network restrictions during live demonstrations.
  • No Transpilation Friction: Source code in index.html, css/war-room.css, and js/app.js matches what executes in the browser 1:1.

Frontend File Organization

04. The Four Workbench Detail Panes

The right-hand column houses the Investigation and Remediation Workbench, split across four dedicated tab panels accessible via click or keyboard shortcuts (1–4).

Pane 1: Finding & Evidence View (1)

  • Severity Pill & CVSS: Color-coded severity badge (CRITICAL, HIGH, MEDIUM) and CVSS score.
  • Component & CWE: Target URL/parameter and official CWE identifier (e.g. CWE-89, CWE-287, CWE-22, CWE-78).
  • Interactive Evidence Viewer: Sub-tabbed code viewer displaying:
    1. HTTP Request: Raw probe headers, query parameters, and test payload.
    2. HTTP Response: Server response headers and reflected syntax error / leaked content.
    3. Raw Trace: Database query failure or signature match logs.
    4. Call Stack: Application call stack identifying the vulnerable source code line.

Pane 2: Proposed Fix (Diff) View (2)

  • Technical Rationale: Clear explanatory card explaining why the defensive mitigation works.
  • Allowlisted Test Validation Badge: Displays the syntax validation command executed (e.g. python -m py_compile) with a green PASSED pill.
  • Interactive Code Diff Viewer:
    • Unified Mode: Displays inline deletions (red) and additions (green) with line gutters and comment callouts.
    • Split Mode: Side-by-side comparison of original vs. remediated code.
    • Diff Stats Pill: Real-time addition/deletion counters (e.g. +6 / -4).
  • Human Approval Gate: Two action buttons (Approve for Demo / Reject Fix). Clicking either sends an API request to the backend and updates the status badge without touching repository files.

Pane 3: Regression Results View (3)

  • Reproducibility Status Banner: Prominent banner displaying either:
    • 🛡️ REMEDIATED — Not Reproducible (Emerald): All 4 checks passed.
    • ⚠️ REPRODUCIBLE — Secondary Bypass Detected (Crimson): Vulnerability persists.
  • 4-Check Matrix Grid: Detailed breakdown of each independent regression test, including test ID, expected status, actual status, and description.
  • Interactive Controls: Includes a Live Replay Suite button and a Toggle Outcome test button.

Pane 4: Live Telemetry Logs (4)

Real-time streaming terminal view showing inter-agent telemetry messages, timestamps, and coordinator state transitions. Automatically scrolls to bottom on new events.

05. Dashboard Table, Modal Dialog & State Engine

1. Dashboard & History View (#view-dashboard)

Accessible via the top navigation bar. Provides a high-level operational overview:

  • Metric Cards: Total local scans, high severity findings, remediations, and average TTR.
  • Search & Filter Bar: Real-time client-side text filter matching Run IDs, target names, or CWE titles, alongside filter chips (All, Complete, Needs Review, Failed).
  • Historical Runs Table: Lists seeded and newly created runs with status pills, timestamps, and Inspect Run buttons that load that run directly into the War Room.
  • Export Audit Report Button: One-click download of the complete sanitized JSON report (AEGIS-Audit-Report-{runId}.json).

2. "Configure New Demo Run" Modal Dialog (#modal-new-run)

An engineered modal dialog (N) designed with responsive constraints and safety bounds:

  • Fixed Header & Footer: Header and action buttons (Cancel / Start Run) remain permanently visible and clickable; the middle form body scrolls smoothly with a custom dark-cyber scrollbar.
  • Locked Target Environment: Hardcoded to authorized local container fixtures with a LOCKED badge to prevent arbitrary external targeting.
  • Test Case Selector (4 Cards): Selectable option cards with custom hover glows for CWE-89, CWE-287, CWE-22, and CWE-78.
  • 3-Column Simulation Outcome Cards:
    ● Complete (Pass) ▲ Needs Review ✕ Regression Fail
  • Mandatory Scope Checkbox: Disables the "Start Run" button with 50% opacity until the user explicitly checks the scope authorization consent.

4. Web Audio Synthesizer in js/simulator.js

Uses browser-native window.AudioContext to generate custom tactile auditory frequencies:

  • stage_advance: 440 Hz → 880 Hz upward frequency chirp.
  • alert: 320 Hz dual-pulse square wave for Sentinel warnings.
  • run_done: Harmonious 3-tone chime (523 Hz → 659 Hz → 784 Hz).
