1. Quick Start & Server Launch

The AEGIS-AGENT platform runs natively on Node.js using built-in HTTP, native SQLite storage (node:sqlite), and native fetch. No complex build pipelines or external dependencies are required.

Step 1.1 Open Terminal in Project Root PowerShell / Command Prompt

Navigate to the project root directory where server.js is located:

cd c:\Users\dell\Desktop\AfterHours
Step 1.2 Verify Environment Variables (.env) Secrets Isolation

The server parses .env on boot. The key is never committed to Git (strictly ignored via .gitignore):

# Environment Settings (.env)
PORT=3000
APP_URL=http://localhost:3000
OPENROUTER_API_KEY=sk-or-v1-****************************************
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_MODEL=google/gemini-2.5-flash
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/aegis_agent

Security Guarantee: The server blocks any direct web request to /.env with a 403 Forbidden status code.

Step 1.3 Start the AEGIS Backend Server Server Startup

Execute the start command:

npm start    # OR execute: node server.js

Confirm the terminal displays the startup banner:

3. Live War Room Synchronous Simulation

To demonstrate the 5-stage synchronous pipeline with bounded retries, state machine validation, and Sentinel gatekeeper alerts:

Workflow 4 Initiating a Multi-Agent War Room Run Live 5-Stage Orchestration

Where: Top Navigation → War Room (Live) tab → Click "Start Demo Run"

Modal Input Options:

Modal Input Field Recommended Option Alternative Paths
1. Authorized Target Local training app (auth-service:v1.4.2) Arbitrary public URLs are rejected server-side.
2. Security Test Case Input validation check (CWE-89) CWE-287, CWE-22, or CWE-78
3. Simulation Outcome Successful Pass (complete) • Sentinel Alert (needs_review)
• Regression Failure (failed)
4. Scope Confirmation Check "I confirm scope authorization" Mandatory — button disabled until checked.
5. Action Click "Start Run"

What Happens Across the 5 Synchronous Stages:

Stage 1 (Scope Gatekeeper): Validates target against allowlist. Rejects out-of-scope targets instantly.

Stage 2 (Red Agent): Injects bounded payload admin' OR 1=1-- against port 8080. Captures HTTP evidence.

Stage 3 (Sentinel Agent): Validates empirical response. Marks finding CONFIRMED. (If Sentinel Alert selected, halts here for review).

Stage 4 (Fix Agent): Prepares minimal candidate patch in isolated memory worktree. Requires human approval.

Stage 5 (Auditor Agent): Runs independent regression tests. Reports 4/4 checks passed.

API 2 Trigger OpenRouter AI Patch Synthesis POST /api/findings/:id/propose-fix

  -Method Post -ContentType "application/json" -Body '{"scope_confirmed":true}'
